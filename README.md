# Tokamak Py

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/Raj123-0/Tokamak-Py/actions/workflows/ci.yml/badge.svg)](https://github.com/Raj123-0/Tokamak-Py/actions)


Tokamak-Py is a high-performance, N-body computational physics engine designed to simulate electrostatic plasma confinement. Rather than relying on standard $O(n^2)$ brute-force calculations or standard Euler integration, this project is built for mathematical rigor and real-time visualization.

## Overview

`Tokamak-Py` is a systems-level tool featuring lexical analysis, parsing, and execution pipelines designed for efficiency and correctness.

## Features

- Modular tokenizer and parser pipeline.
- Comprehensive test suite for language grammar and runtime operations.
- Performance benchmarks evaluating throughput and memory efficiency.

## Getting Started

```bash
git clone https://github.com/Raj123-0/Tokamak-Py.git
cd Tokamak-Py
pip install -r requirements.txt
```

Run tests:

```bash
pytest tests/
```
